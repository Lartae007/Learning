🤖 สำหรับมือถือ Android (Google Chrome):

แตะปุ่มเมนู จุด 3 จุด (⋮) ที่มุมขวาบนของเบราว์เซอร์ → เลือก "ติดตั้งแอป" (Install app) หรือ "เพิ่มลงในหน้าจอหลัก" แอปจะปรากฏบนหน้าจอเหมือนแอปทั่วไป

🍎 สำหรับ iPhone / iPad (Safari):

แตะปุ่ม แชร์ (รูปสี่เหลี่ยมมีลูกศรชี้ขึ้น) ด้านล่าง → เลื่อนลงแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)

📦 ต้องการแปลงเป็นไฟล์ติดตั้ง .APK:

นำ URL หน้าเว็บ GitHub Pages ของคุณไปวางที่เว็บไซต์ฟรีอย่าง PWABuilder.com แล้วกด Package for Android เพื่อดาวน์โหลดไฟล์ .apk ไปติดตั้งลงเครื่องได้ทันที

ตั้งค่า Google Gemini API Key

เปิดใช้งานผู้ช่วยติว AI และวิเคราะห์ภาพกระดาน

🔒 ปลอดภัย 100%: รหัสนี้จะถูกบันทึกไว้ในเบราว์เซอร์บนเครื่องของคุณ (localStorage) เท่านั้น ไม่มีการส่งขึ้น GitHub

วิธีขอรับ Google Gemini API Key ฟรี (ใช้เวลา 30 วินาที):

  1. เปิดหน้าเว็บไซต์ Google AI Studio: https://aistudio.google.com/apikey
  2. เข้าสู่ระบบด้วยบัญชี Google (Gmail) แล้วกดปุ่ม "Create API key"
  3. คัดลอกรหัสที่ขึ้นต้นด้วย AIza... มาวางในช่องด้านบน แล้วกดบันทึก
